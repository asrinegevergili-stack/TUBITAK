Ardışık Sayıların Toplamı

Toplama Kuralları

Kural 1 — 1'den n'e Kadar Toplam

Açıklama. n = terim sayısı. Dizi: 1, 2, 3, …, n (toplam n terim). İlk terim = 1, son terim = n.
Formül. S = n · (ilk + son) / 2 = n(n+1) / 2
Kanıt. Sayıları tersten yazıp alt alta toplayalım:
S = 1 + 2 + 3 + … + (n−2) + (n−1) + n
S = n + (n−1) + (n−2) + … + 3 + 2 + 1
Alt alta toplandığında her sütun:
1 + n = n+1,
2 + (n−1) = n+1,
3 + (n−2) = n+1 …
Her sütunun toplamı n+1'dir. n tane sütun (terim) olduğu için:
2S = n · (n+1) → S = n(n+1)/2.
n+1 = 1 + n = ilk terim + son terim’dir. Bağımsız bir sayı veya "çift sayısı" değildir.
Yazılım. Kullanıcı n (terim sayısı) girer. Program otomatik: ilk = 1, son = n. Sonra S = n·(n+1)/2 hesaplar.
Örnek. n = 6 terim: 1, 2, 3, 4, 5, 6. İlk+son = 1+6 = 7 = n+1. S = 6·7/2 = 21.
S = n(n+1) / 2

Kural 2 — Ortadaki Sayı Yöntemi

Açıklama. n = terim sayısı. Dizi: 1, 2, …, n. n tek olduğunda ortada bir sayı vardır: (n+1)/2. Toplam = terim sayısı × ortadaki sayı.
Formül. S = n · (n+1) / 2 (aynı sonuç)
Kanıt. n = 5 terim: 1, 2, 3, 4, 5. Ortadaki sayı 3 = (5+1)/2. Simetri vardır: 1+5 = 6, 2+4 = 6. Her simetrik çiftin toplamı = ilk + son = 1+5 = n+1. Ortalama = (n+1)/2 = (ilk+son)/2. n tane sayı, her biri ortalamaya göre simetrik. Toplam = n × ortalama = n × (n+1)/2.
Yazılım. Kullanıcı n (terim sayısı) girer. Önce n tek mi kontrol edilir. Tek ise ortanca = (n+1)/2, S = n × ortanca hesaplanır.
Örnek. n = 7 terim: 1, 2, 3, 4, 5, 6, 7. Ortanca (7+1)/2 = 4. S = 7 × 4 = 28. Formül: 7·8/2 = 28.
S = n · (n+1) / 2

Kural 3 — İlk ve Sonu Eşleştirme

Açıklama. n = terim sayısı. Dizi: 1, 2, …, n. İlk + son = 1 + n = n+1. Her simetrik çiftin toplamı aynıdır: n+1. Çift sayısı = n/2.
Formül. S = (n/2) · (n+1). Burada n+1 = ilk terim + son terim.
Kanıt. n = 6 terim: 1, 2, 3, 4, 5, 6. Eşleştir: (1,6), (2,5), (3,4). Her simetrik çiftin toplamı = ilk + son = 1+6 = n+1 = 7. Çift sayısı = 6/2 = 3. S = 3 × 7 = 21. Genel: S = (n/2) · (n+1), burada n+1 = ilk + son.
Yazılım. Kullanıcı n (terim sayısı) girer. Program otomatik: ilk = 1, son = n. çift sayısı = n/2, her çiftin toplamı = ilk+son = n+1, S = (n/2)·(n+1) hesaplar.
Örnek. n = 8 terim: 1, 2, 3, 4, 5, 6, 7, 8. Eşleştir: (1,8), (2,7), (3,6), (4,5). Her çiftin toplamı = ilk+son = 1+8 = 9 = n+1. 4 çift. S = 4 × 9 = 36.
S = (n/2) · (n+1)

Çıkarma Kuralları

Kural 1 — Son ve İlk Terim Arasındaki Fark

Açıklama. n = terim sayısı. Dizi: 1, 2, 3, …, n (toplam n terim). İlk = 1, son = n. Aradaki fark = son − ilk = n−1.
Formül. Fark = n − 1
Kanıt. 1'den n'ye gitmek için n−1 adım gerekir (her adım +1). Son − İlk = n − 1.
Yazılım. Kullanıcı n (terim sayısı) girer. Program otomatik: ilk = 1, son = n. Sonra fark = n − 1 hesaplar.
Örnek. n = 10 terim: 1, 2, …, 10. Son − İlk = 10 − 1 = 9.
Fark = n − 1

Kural 2 — Ardışık İki Sayının Farkı

Açıklama. n = bir terimin değeri. Ardışık iki sayı: n ve n+1. Doğal sayılar tanımı gereği birer birer artar. Fark daima 1'dir.
Formül. (n+1) − n = 1
Kanıt. (n+1) − n = n − n + 1 = 1. Doğal sayı tanımı gereği her sayı bir öncekinden 1 fazladır.
Yazılım. Kullanıcı n (bir terim) girer. Program (n+1) − n hesaplar (sonuç her zaman 1).
Örnek. n = 15 → 16 − 15 = 1. n = 100 → 101 − 100 = 1.
(n+1) − n = 1

Kural 3 — İlk n ve İlk (n−1) Sayının Toplamları Farkı

Açıklama. n = terim sayısı. İlk n sayının toplamından ilk n−1 sayının toplamını çıkarınca son eklenen terim kalır.
Formül. Sn − Sn−1 = n (son terim)
Kanıt. Sn = 1 + 2 + … + (n−1) + n ve Sn−1 = 1 + 2 + … + (n−1). İkinci toplam birincinin parçasıdır. Çıkarınca geriye sadece son terim n kalır.
Yazılım. Kullanıcı n (terim sayısı) girer. Program Sn = n(n+1)/2 ve Sn−1 = (n−1)n/2 hesaplar, farkı alır: sonuç = son terim = n.
Örnek. n = 6 terim: S6 = 21, S5 = 15. 21 − 15 = 6 (son terim).
Sn − Sn−1 = n

Çarpma Kuralları

Kural 1 — Üç Ardışık Sayının Çarpımı

Açıklama. Ortadaki sayı x olan üç ardışık sayının çarpımı x³ − x'e eşittir. Tek değişken x.
Formül. (x−1) · x · (x+1) = x³ − x
Kanıt. Önce (x−1)(x+1) çarpalım. (a−b)(a+b) = a²−b² özdeşliğinden: (x−1)(x+1) = x² − 1. Sonra x ile çarpalım: x · (x² − 1) = x³ − x.
Yazılım. Kullanıcı x girer. Program (x−1)·x·(x+1) ve x³ − x hesaplar, eşit mi kontrol eder.
Örnek. x = 5 → 4·5·6 = 120. Formül: 5³ − 5 = 125 − 5 = 120.
(x−1) · x · (x+1) = x³ − x

Kural 2 — İki Ardışık Sayının Çarpımı Çifttir

Açıklama. x = bir terimin değeri. x ve x+1'den biri tek, diğeri çifttir. Çarpımları daima çift sayıdır.
Formül. x(x+1) her zaman çifttir.
Kanıt. İki durum var:
1) x çiftse: x = 2k. x(x+1) = 2k(x+1) → 2'nin katı.
2) x tekse: x+1 çift. x+1 = 2k. x(x+1) = x·2k → yine 2'nin katı.
Her iki durumda çarpım çifttir.
Yazılım. Kullanıcı x (bir terim) girer. Program x·(x+1) hesaplar ve % 2 === 0 kontrolü yapar.
Örnek. x = 4 → 4·5 = 20 (çift). x = 9 → 9·10 = 90 (çift).
x(x+1) ≡ 0 (mod 2)

Kural 3 — Faktöriyel

Açıklama. n faktöriyel, 1'den n'e kadar tüm doğal sayıların çarpımıdır. Tanım gereği 0! = 1. Tek değişken n.
Formül. n! = 1 · 2 · 3 · … · n, n ≥ 0
Kanıt. n! tanımı gereği n adet çarpandır. Rekürsif olarak: n! = n · (n−1)!, taban durum 0! = 1. n = 0 için boş çarpımın birim elemanı 1'dir.
Yazılım. Kullanıcı n girer. Program n ≥ 0 ve tam sayı kontrolü yapar, sonra 1'den n'e kadar çarpar.
Örnek. n = 5 → 5! = 1·2·3·4·5 = 120. n = 0 → 0! = 1.
n! = 1 · 2 · 3 · … · n

Bölme Kuralları

Kural 1 — Büyüğün Küçüğe Oranı

Açıklama. İki ardışık sayıdan büyüğünün (x+1) küçüğüne (x) bölümü 1 + 1/x şeklinde yazılır. Tek değişken x.
Formül. (x+1) / x = 1 + 1/x, x ≠ 0
Kanıt. (x+1)/x ifadesini paydanın üzerine açalım: x/x + 1/x = 1 + 1/x. x büyüdükçe 1/x küçülür, oran 1'e yaklaşır.
Yazılım. Kullanıcı x girer. Program (x+1)/x ve 1 + 1/x hesaplar, eşit mi kontrol eder.
Örnek. x = 4 → 5/4 = 1.25 = 1 + 0.25 = 1 + 1/4.
(x+1) / x = 1 + 1/x

Kural 2 — Küçüğün Büyüğe Oranı

Açıklama. İki ardışık sayıdan küçüğünün (x) büyüğüne (x+1) bölümü 1 − 1/(x+1) şeklinde yazılır. Tek değişken x.
Formül. x / (x+1) = 1 − 1/(x+1), x ≠ −1
Kanıt. Payı x = (x+1) − 1 yazalım: [(x+1)−1]/(x+1) = (x+1)/(x+1) − 1/(x+1) = 1 − 1/(x+1). Bu her zaman 1'den küçüktür.
Yazılım. Kullanıcı x girer. Program x/(x+1) ve 1 − 1/(x+1) hesaplar, eşit mi kontrol eder.
Örnek. x = 4 → 4/5 = 0.8 = 1 − 0.2 = 1 − 1/5.
x / (x+1) = 1 − 1/(x+1)

Kural 3 — İki Komşu Sayı Çarpımı 2'ye Bölünür

Açıklama. x = bir terimin değeri. İki ardışık sayı x ve x+1'in çarpımı her zaman 2'ye tam bölünür.
Formül. x(x+1) / 2 daima tam sayıdır.
Kanıt. Ardışık iki sayıdan biri çift, biri tektir (Çarpma Kuralı 2). Çift olan sayı 2'ye bölündüğünden, çarpım da 2'ye bölünür. Modüler aritmetikle: ℤ₂ üzerinde x ≡ 0̄ ise x(x+1) = 0̄·1̄ = 0̄; x ≡ 1̄ ise x+1 ≡ 0̄, dolayısıyla x(x+1) = 1̄·0̄ = 0̄.
Yazılım. Kullanıcı x (bir terim) girer. Program x·(x+1) hesaplar, 2'ye bölünüp bölünmediğini (% 2 === 0) kontrol eder.
Örnek. x = 7 → 7·8 = 56, 56/2 = 28 (tam sayı). x = 4 → 4·5 = 20, 20/2 = 10.
2 | x(x+1)
Bu proje ardışık sayılar üzerine geliştirilmiştir.
